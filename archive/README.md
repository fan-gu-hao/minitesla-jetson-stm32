# 歷史資料／Historical archive

此處保存原始文件、照片、早期程式、舊建置產物與歷次交付說明，便於追溯專案形成過程。這些資料沒有全部改寫成最新版文件。

This archive retains original documents, photos, early source, old build products, and staged release notes. It preserves project history rather than rewriting every historical document into the current presentation.

| 目錄／Directory | 內容／Contents |
| --- | --- |
| `documents/` | 原始技術文件與早期操作筆記。Original technical documents and notes. |
| `photos/` | 原始硬體照片與資料夾截圖。Original hardware photos and folder screenshots. |
| `early_sources/` | 早期獨立程式、找回的舊停車工具與原設定。Earlier programs and superseded helper/configuration. |
| `legacy_builds/` | 舊韌體／SDK 建置產物、被取代的驅動與設定。Legacy outputs and superseded files. |
| `release_notes/` | 當時增量更新的使用說明。Historical incremental-release instructions. |
| `restoration/` | 先前復原包說明、來源與校驗紀錄。Prior recovery-package records. |

原文件可能包含已取消的構想、舊功能定位、過期路徑或不同階段的驗證敘述。主要展示範圍以根目錄 README 為準；停車相關統一視為實驗性保留。

Historical material may include cancelled plans, superseded claims, old paths, or stage-specific verification statements. The root README defines the main demonstration scope; parking-related code is retained as experimental.

舊 `.hex`／`.axf` 與對應建置紀錄不可當成目前韌體來源的最新產物。原始建置紀錄集中於 [`logs/`](../logs/)，避免在此重複保存同一份紀錄。

Old firmware binaries and build records are not fresh artifacts for the current source. Original build logs are centralized in [`logs/`](../logs/) to avoid duplicate copies.
