## 放大的展示車位

你已同意車位可以放大，因此本版選用以下展示尺寸，並直接寫入參數：

| 項目 | 尺寸 |
| --- | --- |
| 車位內寬 | **180 公分**，左右擋板內側之間 |
| 車位內深 | **130 公分**，入口至後方擋板內側 |
| 擋板 | 左、右、後三面實體擋板，入口開放 |
| 擋板高度 | 必須高於雷達掃描平面；目前雷達高度約 31.5 公分，並須讓對應測距器能看到反射面 |
| 停妥後目標車尾距後擋板 | 沿用 60 公分 |

這是本版選定並經模擬檢查的展示配置，不是本車的物理最小車位，也不是已搭建完成的場地量測值。實際擋板請依這個內寬、內深配置；舊的 40 × 55 公分不適用這份程式設定。

只留一塊 180 × 130 公分的車位還不足以轉向，入口外也需要轉向空間。以下是本次使用的**完整理想模擬場景**，可依此安排展示；它不是任意場地都能成功的保證：

| 場地或起始位置 | 配置 |
| --- | --- |
| 周圍矩形空間 | 長 340、寬 280 公分，有可供四向測距的反射面 |
| 車位後方到周圍後牆 | 50 公分 |
| 車位左右擋板到周圍側牆 | 各 50 公分 |
| 車位入口到周圍前牆 | 160 公分 |
| 起始後軸中心 | 位於入口外 62.5 公分，對準入口寬度的中央 |
| 起始車頭方向 | 沿走道，與車位深度方向垂直；從車位內看向入口外，車頭朝左 |

模擬先轉向對位，再倒入。開始時必須能觀察到三面車位與可行駛空間。測距器實際安裝、反射材質、地面與遮擋仍會影響實車結果；無效測距維持停止處理。

## 這次操作

在原本環境停止 Jetson 服務：

```bash
cd "$HOME/Desktop/jetson orin nano"
python3 minitesla_service.py stop
```

將本包的 `Jetson/minitesla_sensors/vehicle_config.py` 覆蓋到上述資料夾內的 `minitesla_sensors/vehicle_config.py`。參數與啟用狀態已寫好，不需要再輸入資料或手動修改。

```bash
python3 minitesla_service.py restart
```

電腦操作方式相同：先按空白鍵回待命，再按 K 自動找位入庫。`enabled=True` 只開放停車指令，開機仍為待命，不會自動行駛。

可選擇執行 `python3 parking_setup.py status` 查看固定值；`python3 parking_setup.py preview` 仍是讀取即時快照、不移動車輛的預覽工具。兩者均不需要輸入車輛參數。

## 本次驗證

- 固定參數通過原有範圍與幾何驗證；啟動載入確認左右半徑 0.48 公尺、後懸 0.14 公尺、雷達方向及位置正確。
- 主程式整合確認：K 已開放、開機待命、雷達座標為車尾起算 X=300、Y=0、Z=315 毫米。
- 以這份實際交付的參數、未修改的停車演算法，完成一個從車身垂直車位開始的射線與車輛運動學模擬：轉向、換向、倒車、穩定後完成。
- 模擬到位後，後軸中心距目標約 1.91 公分、角度差約 5.19°，在原有 8 公分／6° 容許範圍內；理想車身沒有碰撞。
- 每 5 毫秒模擬子步檢查四向射線，距離全程約 560～1923 毫米，維持原有有效距離條件。
- 四向測距器在模擬中位於車身前後、左右外框的理想位置；未模擬實際光學材質、打滑、舵機非線性與煞停延遲，因此不等同於實車結果。
- 不更動 Jetson 45 公分停止門檻、路徑碰撞餘量或 M4 既有保護。程式通過 Python 3.8 語法檢查。
